# CV Portfolio

Trang portfolio/CV cá nhân giới thiệu Đào Ngọc Anh Tú, định hướng Frontend Developer. Dự án được xây dựng bằng HTML5 và CSS3 thuần, không cần cài đặt thư viện hay bước build.

## Nội dung

- Giới thiệu cá nhân và ảnh đại diện
- Kỹ năng
- Bốn thẻ dự án mẫu
- Thông tin liên hệ
- Bố cục responsive với các breakpoint cho tablet và desktop

## Chạy dự án

Mở `index.html` trực tiếp bằng trình duyệt hiện đại. CSS và hình ảnh được tải từ các đường dẫn tương đối trong dự án.

## Cấu trúc

